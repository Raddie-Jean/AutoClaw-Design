# AutoClaw 响应式交互实验室 V14

打开 index.html 即可使用，无需安装或联网。app.html 为不含控制面板的独立界面。

依据用户提供的首页与任务执行 SVG、执行页 PNG，以及工作区 V09 tokens；沿用原生 SVG 图标。没有通过 Intelligent UI 插件生成（未找到该工具）；Figma 在线接口受套餐额度限制，因此以提供的本地设计稿为基准。

支持首页、执行代码、执行预览三种视图；自适应、1512、834、390 px 预览；任务默认、执行中、完成、失败、空状态；输入框默认、聚焦、禁用、错误；按钮默认、悬停、禁用、加载；侧栏、文件树、圆角、字号可调。

可执行流程：输入任务并发送 → 执行中 → 自动完成 → 查看预览；也可停止、模拟失败后重试、切换文件、下载模拟代码。模型、权限、项目、附件和平台配置为本地模拟。附件不上传，平台不连接，购买不付款。

尺寸响应：1200 以下压缩侧栏和文件树；900 以下采用抽屉导航；600 以下代码/预览覆盖工作区，关闭后返回对话。参数面板的设备模式固定实际 iframe 宽度，窄窗口可横向查看。

视觉匹配以结构、字体、灰阶、间距和组件形态为目标；代码内容为模拟，头像和少数符号为近似，不宣称逐像素一致。响应式规则、预览内容和参数面板为本次新增设计。

## 组件参数

| 组件 | 默认参数 | 模拟状态 |
|---|---|---|
| 导航侧栏 | 宽 280 px，可调 200–320 px | 展开 / 收起 / 手机抽屉 |
| 工作区 | 白色，圆角 16 px，弹性填充 | 首页 / 执行 / 预览 |
| 输入框 | 圆角 25 px，可调 0–32 px，内边距 16 px | 默认 / 聚焦 / 禁用 / 错误 |
| 发送按钮 | 32 × 32 px，圆形 | 默认 / 悬停 / 禁用 / 加载 / 停止 |
| 文件编辑器 | 桌面宽 464 px | 代码 / 预览 / 关闭 |
| 文件树 | 宽 220 px，可调 150–260 px | 显示 / 隐藏 / 文件选中 |
| 正文 | PingFang SC，14 px，可调 12–18 px | 实时字号调整 |
| 任务 | 本地模拟，2.4 秒完成 | 默认 / 执行 / 完成 / 失败 / 空 |

验证：运行 `python3 verify.py`，使用本机 Chrome 与 Playwright。截图包括完整实验室、独立桌面界面及 834/390 px 的首页与执行页。
