# AutoClaw 原生 SVG 图标库 V06

共 168 个文件，直接从本机 AutoClaw 2.0.1 安装资源提取。未使用截图描摹、PNG自动描边或凭印象重绘图标。

01 为应用自定义 SVG，保留原始路径、viewBox、描边与填充规则。未确认用途的文件用 custom 编号，未猜测命名。
02 为应用程序实际内置的 Lucide 图标，不是网上近似替代版。保持原始 24×24、2px 描边。
03 为应用独立 SVG 资源，包含品牌、渠道和场景素材；它们不全是线性图标。

## 导入 Figma

把所需 SVG 拖入画布。也可导入各分类的“图标总览.svg”，每枚图标独立成组，名称完整显示。均为24×24显示尺寸，保留原始坐标系。单色已将 currentColor 固定为 #333333，无外部CSS或字体依赖。

自定义图标部分是原稿扩展描边的填充路径，调整粗细需编辑路径；Lucide 是真实stroke描边，可直接调整粗细。不要给全部图标统一叠加描边。

应用原生不同图标族的设计尺寸和线宽本来就不同，未强行统一路径以免改变原稿。动态加载图标因依赖运行时参数未纳入。截图中的个别场景图标原生是PNG，也未假装SVG收录。

每枚文件来源见manifest.json。此包未进行真实Figma导入验证；已进行SVG解析、无位图和无外部依赖检查，以及渲染检查。

原始资源中四个SVG实际内嵌PNG，已排除，未将它们冒充纯矢量图标。

另排除三枚依赖运行时属性、静态渲染为空白的图标。
