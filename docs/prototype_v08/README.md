# AutoClaw Design 工作区 · 初版可点击原型

直接打开 `index.html` 即可体验；建议使用 1365 × 851 或更宽的桌面浏览器窗口。无需安装依赖。

## 体验路径

1. 在还原的 AutoClaw 首页点击左侧「邀请成员流程」，进入设计成果总览。
2. 查看 A / B / C 三个草图方向，打开方向 B 的可运行预览。
3. 在预览中选择「改文字」「智能编辑」或「画笔圈选」，限定修改位置、意图和保留项。
4. 生成隔离候选，对比原版与候选；可继续调整、放弃，或采纳为 v4。
5. 设计师采纳后进入 PM 概念评审；确认方向后，再检查 Demo 的手机、桌面和关键状态。
6. 完成 Demo 复核后进入交付页，查看版本快照与开发接手清单。

## 设计说明

原型基于用户提供的 AutoClaw 首页截图，沿用侧边栏、顶部账户区、任务入口和项目结构。新增的 Design 工作区将「方向选择」「局部修订」「候选对比」「概念评审」「Demo 体验评审」「交付」串成一条链路。画笔圈选采用可交互的框选模拟，AI 识别、代码修改、实际运行回归和生产源码交付尚未接入。

截图 `00_home.png` 至 `06_handoff.png` 对应上述主要界面。Figma 文件中的 `02 · AutoClaw 界面还原` 已完成可编辑的首页底稿；`03 · Design 工作区原型` 已建立首页壳层。后续画面目前以本地可点击原型为准，尚未同步到 Figma 原型页。
