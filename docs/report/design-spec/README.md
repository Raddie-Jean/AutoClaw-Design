# AutoClaw 可视化设计规范 V10

七张1440×1080规范画板：总览、颜色、字体与空间、布局、组件、图标、交付。规范内容基于V09，未改变其执行参数。

把svg文件夹中的文件拖入Figma即可；整套规范总览.svg可一次导入。图形、色板、布局示意和图标为矢量；文字保留SVG text。导入Figma后文字可能转轮廓。

如需原生文字，使用figma-plugin文件夹中的本地导入工具，选择figma-editable-import下对应JSON；无网络上传。工具仅通过语法检查，未在Figma实测。布局示意为缩略图，文字标注为逻辑尺寸。

Figma MCP额度仍受限，本次未直接创建Figma云文件、组件实例、变量集合或自动布局。颜色、字体、阴影沿用已标注的当前执行值；扩展建议没有冒充原稿确认参数。完整文本与102项参数位于reference。
