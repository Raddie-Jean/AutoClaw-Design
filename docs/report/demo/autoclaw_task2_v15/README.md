# AutoClaw 测试2 · 设计产物与协作评审 V15

日期：2026-10-12。

## 设计与操作
左侧保留任务过程与产出物窗口，设计产物按 AutoClaw 的原型 / 最终文件 / 工作文件 / 资产层级整理。右侧保持统一的产物顶部，支持预览、桌面、平板、手机和幻灯片查阅入口，以及画布 / 评审 / 代码 / 图层 / 版本标签。

评审流程：载入已有产物 → 发起评审并确认范围 → 点击画布头像查阅 → 根据对象建议或 Intelligent UI 参数生成候选 → 对比工作版 → 采纳 → 回到原评论回复并确认解决 → 导出记录与工作版SVG。

画布内可切换评审模式。右侧的“记录 / 参数”用于在简洁评审记录和 Intelligent UI 修改之间切换。参数支持标题、输入卡片圆角、侧栏背景、工具栏文字颜色。修改先生成候选，工作版保留到明确采纳后才更新。历史版本只读；意见、回复和解决状态固定在原版本。查阅原评论会回到对应历史画布，候选画布不混入原版本头像。

## SVG与Figma
screens 中为14张1512×945可编辑矢量设计稿。previews 为对应浏览器截图。SVG 可直接拖入 Figma；如导入器将文字转为轮廓，可使用配套 figma-plugin 导入 figma-editable-import 中的 JSON，以重建原生文本。插件未在 Figma 内实测，SVG不包含组件实例、自动布局与原型连线。
Figma 修改后可导出同名 SVG 替换 screens 文件，图库立即反映调整；交互HTML仍需手动同步对应样式与参数。

## 验证
已实际验证：发起评审、头像定位、评审参数切换、建议候选、工作版对比、采纳、回到历史评论回复、确认解决、Intelligent UI 参数生成独立候选、三版历史保留、SVG与JSON真实下载。下载SVG验证了标题变化与圆角属性，JSON验证了版本、修改次数和原评论的解决状态。
14张SVG均通过XML解析、尺寸检查、无位图image检查、SVG text数量与配套JSON文字记录一致性检查；已在浏览器查看SVG渲染。两条任务切换后，测试2评审状态保留，测试1仍是独立初始任务。修订后的评审页面在实际候选操作中无控制台错误或警告。

## 原型边界
参与者、AI建议和生成均为本地模拟，不发送真实邀请。对话记录修改意图，参数和预设建议驱动实际矢量变化，不提供通用自然语言编辑。手机/平板入口模拟画稿查看尺寸，尚未重排产物内部的响应式布局；幻灯片入口按版本列表查阅。刷新页面重置演示状态。
